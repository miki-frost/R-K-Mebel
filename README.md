# Strona internetowa – Stolarnia Meblowa

Prosta, responsywna strona internetowa dla stolarni meblowej.  
Projekt ma charakter informacyjny i prezentuje ofertę firmy, galerię realizacji oraz dane kontaktowe.

Strona tworzona klasycznie w HTML i CSS, bez frameworków i bibliotek JS.

---

## 📌 Cel projektu

- prezentacja usług stolarni meblowej
- pokazanie wybranych realizacji
- ułatwienie kontaktu z klientem
- utrwalenie podstaw HTML, CSS oraz responsywności
- podstawy SEO
- nauka JavaScipt w praktyce

---

## 🛠 Technologie

- **HTML5** – semantyczna struktura strony  
- **CSS3** – layout (Grid, Flexbox), responsywność (media queries)  
- **JavaScript** (opcjonalnie) – proste interakcje (np. menu mobilne)

Brak frameworków – projekt oparty na czystych technologiach webowych.

---

## 📱 Responsywność

Strona tworzona w podejściu **mobile first**:
- układ oparty o CSS Grid i Flexbox
- breakpointy dostosowane do tabletów i desktopów
- czytelna nawigacja na urządzeniach mobilnych
